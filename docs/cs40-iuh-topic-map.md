# CS 40 (infracourse.cloud) → IUH topic map

**Source of inspiration:** [https://infracourse.cloud/](https://infracourse.cloud/) — Stanford CS 40, *Cloud Application Deployment*, Winter 2024.

IUH course: *Service-Oriented Architecture and Cloud Computing*  
Repository: [nglelinh/service-oriented-architecture-and-cloud-computing-iuh](https://github.com/nglelinh/service-oriented-architecture-and-cloud-computing-iuh)

This map is for instructors and contributors. **Do not copy CS 40 assignment specifications, rubrics, or wording into IUH materials.** Lessons, labs, and `PROJECT.md` in this repository are original.

| CS 40-style block | IUH home |
| --- | --- |
| Foundations / building blocks | Chapter 01 (required) |
| Networking, DNS, TLS | Optional `01-07`; Labs A and C |
| Storage / databases | Chapters 07 and 10 |
| Containers / orchestration | Chapters 08–09; Lab A |
| Infrastructure as Code | Chapter 14; Lab B; CDK/Pulumi compare in `14-01` |
| IAM / security | Chapter 13 required; optional `13-02` |
| Observability | Optional `02-02`, `13-02`, depth `13-03` |
| Serverless / ML + HPC serving | `08-04`, `08-05`, `01-06`, `12-02` |
| CI/CD | `13-01` survey; optional `13-04` |
| Cost / ethics | `01-06`, `12-03`, Lab C |
| Final deploy project | Chapter 15 capstone + root `PROJECT.md` (pairs) |

IUH remains platform- and data-first (Hadoop, Spark, NoSQL). Chapter 15 is an optional **Deploy Track** hub, not a replacement spine.
